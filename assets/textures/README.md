Block textures (16x16 PNG), one file per face type. See blocks.py for how
they are used. Missing files are replaced by a plain colored square.

Currently used: grass_block_top, grass_block_side, grass_block_side_overlay,
dirt, cobblestone, oak_log, oak_leaves.

Note: grass top, grass side overlay and oak leaves are grayscale in the
original game and tinted by biome. We show them untinted for now.
